# H2 Lifestyle

A premium, responsive storefront concept for a Bangladeshi lifestyle shop, built with plain HTML, CSS and JavaScript. No build step or dependencies are required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy on GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
4. After the deployment finishes, open the Pages URL shown in Settings.

The site is static and can be hosted on GitHub Pages for free. Product photography and Google Fonts are loaded from external services and therefore need an internet connection.

## Store setup before launch

- Replace the demo product details, pricing, and product photography in `app.js` with real inventory.
- Update the WhatsApp number (`88018825358885`) and contact details in `index.html` and the checkout handler in `app.js`.
- Connect the newsletter form and checkout to a real service if you need to collect emails or accept online payments. The current checkout shares an order summary through WhatsApp; no payment is processed on the site.

## Included

- Responsive luxury-inspired storefront with category navigation and product search/filtering.
- Product detail modal, persistent browser wishlist and cart, quantity controls, and BDT formatting.
- WhatsApp order handoff, delivery messaging, and a demo newsletter interaction.
